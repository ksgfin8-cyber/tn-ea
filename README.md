# Tortuga Ninja (TN)

Este repositorio conserva el modelo Tortuga Ninja como objeto de estudio bajo [RDL-PB-001 v0.1](docs/program/RDL-PB-001_v0.1_original_propuesta.md).

## Contenido

- [Motor TypeScript](src/engine) con Γ, GEI y Φ, el conjunto de teorías, los contratos de estado y los módulos de apoyo.
- [Referencia histórica de ejecución secuencial](src/simulator/backtest.ts) con el orden por barra de los operadores, la política de acción y las actualizaciones de estado. Se conserva para reconstruir la conducta del modelo.
- [Especificación matemática v5.4](TN-LAB-Mathematical-Specification.md), [especificación científica canónica v5.7](TN-LAB-CANONICAL-SCIENTIFIC-SPECIFICATION.md) y [arquitectura computacional](TN-LAB-Computational-Architecture.md).
